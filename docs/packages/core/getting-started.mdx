# UI-Router Core

`@uirouter/core` is the framework-independent routing engine behind every
UI-Router package. It manages states, transitions, URLs, parameters, and
resolve data. The framework packages add the parts that depend on a framework,
such as views and links.

## Do you need to install it?

Usually not. Each framework package brings Core with it, so start with the
guide for your framework:

- [UI-Router for Angular](/frameworks/angular)
- [UI-Router for React](/frameworks/react)

Install Core directly when you build an integration for another framework, or a
plugin that works with any framework:

```bash
npm install @uirouter/core
```
