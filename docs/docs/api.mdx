# API reference

Each UI-Router package has its own API reference, generated from its TypeScript
source. Packages are released independently, so each card shows the package's
current version line.

**How this reference is organized:** each package's menu lists its main APIs,
grouped by topic. Every other public type still has its own page; follow the
links from the listed pages to reach it.
